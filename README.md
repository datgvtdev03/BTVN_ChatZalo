# BTVN_ChatZalo

Ứng dụng chat Zalo được viết lại với code sạch, hiện đại và có cấu trúc tốt.

## ✨ Tính năng

- 💬 Gửi và nhận tin nhắn real-time
- 😊 Bộ chọn emoji tích hợp
- 🌙 Chế độ sáng/tối (Dark/Light theme)
- 📱 Responsive design cho mobile
- 💾 Lưu trữ tin nhắn trong localStorage
- ⌨️ Keyboard shortcuts
- 🎨 UI/UX hiện đại theo phong cách Zalo
- 🔄 Auto-reply simulation
- ⏰ Timestamp cho tin nhắn
- 🚀 Smooth animations và transitions

## 🚀 Cách chạy

1. Clone repository:
```bash
git clone <repository-url>
cd BTVN_ChatZalo
```

2. Mở file `AppZalo/index.html` trong trình duyệt hoặc sử dụng live server.

## 📁 Cấu trúc thư mục

```
AppZalo/
├── index.html      # Cấu trúc HTML chính
├── styles.css      # CSS với modern design và responsive
└── script.js       # JavaScript với ES6+ và clean code
```

## 🎯 Keyboard Shortcuts

- `Enter`: Gửi tin nhắn
- `Ctrl/Cmd + K`: Xóa tất cả tin nhắn
- `Ctrl/Cmd + D`: Chuyển đổi theme
- `Escape`: Đóng emoji picker

## 🛠️ Công nghệ sử dụng

- **HTML5**: Semantic markup
- **CSS3**: Modern CSS với CSS Variables, Flexbox, Grid
- **JavaScript ES6+**: Classes, Arrow functions, Modern APIs
- **Font Awesome**: Icons
- **LocalStorage**: Lưu trữ dữ liệu
